                      Sauvegarde

                      Vos données restent sur vos appareils. La sauvegarde est chiffrée avec votre mot de passe : sans lui, le fichier est illisible, même s'il passe par iCloud ou AirDrop.

                      Sauvegarde automatique

                      Envoyer sur l'iPhone

                      1. Envoyez le fichier de sauvegarde par AirDrop sur votre iPhone.
                      2. Sur l'iPhone, ouvrez Mon Budget (l'app installée sur l'écran d'accueil), onglet « Sauvegarde ».
                      3. « Choisir le fichier… », puis votre mot de passe de sauvegarde.

                      Restaurer une sauvegarde

                      Remplace toutes les données de cet appareil par celles du fichier.

                      Importer un relevé

                      Déposez vos relevés bancaires en PDF. Ils sont lus sur cet appareil : rien n'est envoyé nulle part.
